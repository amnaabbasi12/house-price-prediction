## Overview
# house-price-prediction
Data analysis and machine learning project that explores housing data, performs EDA, visualizes trends, and predicts house prices using Linear Regression.

## Dataset
Housing dataset containing features such as:
- Bedrooms
- Bathrooms
- Living Area
- Price

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

## Workflow
1. Data Cleaning
2. Exploratory Data Analysis
3. Data Visualization
4. Model Training
5. Model Evaluation

## Model
Linear Regression

## Results
The model predicts house prices based on key housing features.
